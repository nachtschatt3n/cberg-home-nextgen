### Prometheus v3.15.0 (released 2026-09-24) — checked against our config

From `CHANGELOG.md` on branch `release-3.15` (`VERSION` at tag `v3.15.0` = `3.15.0`):

- *"[CHANGE] Logging: Deprecate `--log.level`; use `runtime.log_level` configuration to
  supply the default level."* — **deprecated, not removed**. The operator renders no
  `--log.level` for our Prometheus (live args: config.file, web.enable-lifecycle,
  external-url, route-prefix, tsdb.path, enable-admin-api, wal-compression,
  web.config.file — measured 2026-10-05). No effect.
- *"[ENHANCEMENT] TSDB: Stabilize the XOR2 float chunk encoding. `--enable-feature=xor2-encoding`
  is deprecated; use `storage.tsdb.chunk_encoding.floats: xor2` instead."* — **opt-in**;
  we set neither (premise `no-opt-in-tsdb-encoding`). This is the fact the rollback
  rests on: 3.15.0 keeps writing default XOR chunks, so 3.14.0 can re-open the TSDB.
- *"[CHANGE] PromQL: A range query whose `end` was not aligned to `step` …"* and
  *"Do not register a start timestamp reset …"* — query-stats / start-timestamp
  (feature-flagged) internals; no rule semantics change.
- Bugfixes relevant to us: *"TSDB: Don't silently drop samples when head garbage
  collection removes a series while it is being appended to"*, *"TSDB: Prevent query
  panics during series eviction after WAL replay"*, *"TSDB: fix potential deadlock
  between mmapSeriesChunks and gcSeries"*, *"Scrape: Do not append a stale marker for a
  series that is still exposed …"*.
- New features (Unix-socket scraping, OM2.0, zstd scrape, `--auto-gomemlimit.refresh-interval`,
  runtime log level) are all opt-in and unconfigured.

### Why the node-exporter annotation removal is inert here

Nothing scrapes Services by annotation. Prometheus scrapes node-exporter through
`servicemonitor/kube-prometheus-stack-prometheus-node-exporter` (3 targets up,
2026-10-05). The only annotation-driven scraper, `opentelemetrycollector/otel-operator-daemon`,
has three jobs — `kubernetes-pods` (role **pod**, keys on the POD annotation, which the
node-exporter pods do not carry), `node-exporter` (static) and `kubelet` (role node) —
none with `role: service`/`endpoints`. §4.3 asserts both the removal and that the
ServiceMonitor targets still arrive.
